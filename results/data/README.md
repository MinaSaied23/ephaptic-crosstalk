# Simulation outputs

Every file here is written by a script in `src/experiments/`; nothing is edited by hand.
`python run_all.py` regenerates all of them. Each `.meta.json` records the parameter set of
the corresponding run.

| File | Generated by | Contents |
|---|---|---|
| `e01_abeta_control.csv` | `e01_controls.py` | Uncoupled Aβ fiber: stimulation threshold, conduction velocity, AP excursion at z = 4 mm, electrode-site peak |
| `e01_cfiber_controls.csv` | `e01_controls.py` | Uncoupled C-fiber variants: resting potential, passive time constant, AP peak, conduction velocity, APD50 |
| `e02_refinement.csv` | `e02_convergence.py` | Δt and Δz refinement of the coupled endpoints, both ionic treatments |
| `e02_kcl.csv` | `e02_convergence.py` | Physical current-balance residual of the compartment |
| `e02_lagged_vs_monolithic.csv` | `e02_convergence.py` | Earlier lagged scheme vs the monolithic scheme in the earlier geometry |
| `e02b_fast_variants.csv` | `e02b_fast_variants.py` | Time-step check for the fast C-fiber variants and near the Aβ block boundary |
| `e03_n_sweep.csv` | `e03_n_sweep.py` | Synchronous volleys, n = 1–300 (production configuration) |
| `e04_geometry.csv` | `e04_geometry.py` | Per-fiber-sleeve closure: response vs sleeve width |
| `e04_mean_field.csv` | `e04_geometry.py` | n fibers sharing A_e vs one fiber in A_e/n |
| `e05_kappa.csv` | `e05_kappa.py` | Extracellular leak κ = 10⁶–10¹¹ m⁻² × n |
| `e06_kinetics.csv` | `e06_kinetics.py` | C-fiber kinetic variants × n × κ |
| `e07_strength_duration.csv` | `e07_threshold.py` | Strength–duration curves of the isolated C-fiber |
| `e07_safety_factor.csv` | `e07_threshold.py` | Gain α* on the recorded u_e needed to evoke an AP |
| `e08_jitter.csv` | `e08_jitter.py` | Onset dispersion window W = 0–2 ms |
| `e08_jitter_convergence.csv` | `e08_jitter.py` | Convergence in the number of onset phases and in Δz |
| `e09_trains.csv` | `e09_trains.py` | 5-pulse trains at 50–400 Hz, per-pulse peaks |
| `e10_equilibria.csv` | `e10_bias.py` | Space-clamped C-fiber equilibria and their linear stability vs bias |
| `e10_bias.csv` | `e10_bias.py` | Coupled runs with a sensitizing bias, each with a no-stimulus control |
| `e11_full_length.csv` | `e11_full_length.py` | Earlier full-length geometry, both treatments of the electrode current |
| `e12_lesion_stimulus.csv` | `e12_lesion_stimulus.py` | Lesion length 1–7 mm and stimulus 1.2–20 × threshold |
| `e13_waveforms.npz` | `e13_waveforms.py` | Space–time fields (u_e, C-fiber ΔV, Aβ V_m) for the figures, stored at reduced resolution |

## Columns common to the sweep files

| Column | Meaning |
|---|---|
| `model` | C-fiber membrane: `HH` (classical) or `NavC` (Nav1.8/1.9) |
| `n_abeta` | Number of synchronously stimulated Aβ fibers sharing the compartment |
| `status` | `quiescent` (returned to rest), `spike` (propagating AP, run stopped early), `completed`, `diverged` |
| `dv_lesion_mV` | Peak C-fiber depolarization inside the lesion, relative to the exact resting state |
| `dv_lesion_z_mm` | Position of that peak |
| `v2_peak_lesion_mV` | Absolute C-fiber membrane potential at that peak |
| `dv_mid_mV` | Peak depolarization at the lesion midpoint (z = 5 mm) |
| `hyp_lesion_mV` | Largest hyperpolarization in the lesion (negative) |
| `v2_rest_mV` | C-fiber resting potential (exact steady state) |
| `ue_min_mV`, `ue_max_mV` | Extremes of the extracellular potential |
| `c_spike` | A propagating C-fiber action potential occurred (primary endpoint) |
| `c_overshoot` | The C-fiber crossed 0 mV anywhere, whether or not it propagated |
| `c_init_z_mm`, `c_init_t_ms` | Where and when the first overshoot occurred |
| `c_cv`, `c_span_mm` | Conduction velocity of the overshoot front and the length of cable it covered |
| `ab_conducts` | The Aβ action potential reached the last node |
| `ab_cv_lesion`, `ab_cv_free` | Aβ conduction velocity inside the lesion (nodes 3→7 mm) and before it (0→2 mm) |
| `stim_nA` | Aβ stimulus current actually used |
| `r_e`, `A_e_um2` | Longitudinal resistance per unit length and cross-section of the compartment |
| `t_end_ms` | Simulated time at which the run stopped |
